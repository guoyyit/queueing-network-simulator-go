# Queueing Network Simulator (Go)

一个可在本地运行与验证的排队网络离散事件仿真库，用于对由多个工作站组成的
服务系统做容量规划与延迟评估。纯 Go 标准库实现，无外部依赖。

## 快速开始

```bash
go build ./...
go test ./...
go run ./cmd/qsimdemo
```

## 能力概览

- 多个工作站组成网络：每站可配置服务台数、服务时间分布、队列容量、调度策略。
- 调度策略：`FCFS` 先到先服务、`LCFS` 后到先服务、`PriorityNP` 优先级非抢占、
  `PriorityPP` 优先级抢占（优先级数值越小越高）。
- 两种流量模型：
  - 开放模型 `Open`：任务按独立泊松过程（指数间隔、可配置速率）外部到达，
    按转移概率矩阵路由到下游或离开系统。
  - 封闭模型 `Closed`：常驻任务总数固定（时刻 0 在工作站 0 注入），无外部到达。
- 有限容量与两种阻断语义：
  - `Reject`：目标等待队列满时拒收，任务计入网络级与工作站级独立拒绝计数，
    不静默丢失（守恒式：接纳数 = 离开数 + 拒绝数 + 在站人数）。
  - `Block`：发送方阻塞。服务完成的任务连同其服务台挂起，服务台保持占用、
    不服务其他任务，直到目标出现空位才转入；期间无拒绝。
- 稳态统计：吞吐、利用率、排队时长均值/分位数、逗留时长均值/分位数、
  时间平均等待队长、时间平均站内人数，以及批均值法的 t 分布置信区间。
- 检查点/恢复：可保存完整仿真状态为 JSON，恢复后续跑结果与一次连续运行
  逐位一致，包含随机流位置、事件表、队列、服务台、阻塞、时间序列与累加器。
- 并行复制：同一实验并发运行多个独立复制，复制间不共享可变状态或随机流，
  结束后合并跨复制点估计与样本标准差。

## 时间推进机制

采用下一事件递增（next-event increment）的离散事件仿真，不设固定时间步长：

1. 未来事件表 `Calendar` 是一个最小堆，事件类型只有“到达”和“服务完成”。
2. 每步弹出优先级最高的事件，把仿真时刻跳到该事件时刻并处理。
3. 外部到达在事件被实际取出时才创建任务并续调下一到达，因此不会多消耗
   随机数；这保证检查点在任意时刻切分后续跑与连续运行完全一致。
4. 服务台、队长等时间持久型量记录为分段常数的完整变化史（`stats.TimeAverage`），
   在任意时间区间上解析积分，支持预热剔除与按时间分批。

### 同刻活动的确定性规则

多个事件落在同一时刻时，先后次序由以下全序规则唯一确定：

1. 时刻更早者先；
2. 同刻：**到达事件先于服务完成事件**；
3. 再同：工作站编号小者先；
4. 再同：顾客优先级数值小者（高优先级）先；
5. 再同：顾客 ID 小者先；
6. 最后以入表序号 `Seq`（单调递增、确定分配）兜底。

同一时刻内的瞬时中间状态（例如“完成→离开→启动下一服务”产生的零时长过渡）
不会回改已关闭时间段的历史值。给定相同配置与随机种子，全部统计输出可复现。

### 抢占语义

`PriorityPP` 下，当更高优先级任务到达且所有服务台忙时：

- 选取在服任务中优先级最低（同优先级取 ID 最大）者进行抢占；
- 被抢占任务的**剩余服务时间** = 原计划完成时刻 − 抢占时刻，被保留在任务上，
  并回到等待队列最前；恢复服务时继续使用该剩余时间，**不重新采样**；
- 抢占者立即占用该服务台；被抢占者排队期间等待时长在其最终开始服务时
  一并记录，恢复时刻不重复计时。

### 随机数

- 每个仿真使用相互独立的随机子流：一个外部到达流、一个路由决策流、
  以及每个工作站各自的服务时间流（`rng.SubSeed`），避免到达与服务因共用
  一条流而产生诱导相关（这会使 M/M/1 队长偏离解析解）。
- 底层为 PCG-XSH-RR，种子经 SplitMix64 混合；`Uint64`/`Float64` 均为纯函数
  推进，位置计数与内部状态完整纳入检查点。
- 并行复制使用 `rng.ChildSeed(seed, index)` 派生各自独立种子。

## 统计口径

- 稳态区间为 `[Warmup, EndTime)`；预热期样本不进入稳态均值/分位数/置信区间。
- **吞吐** `Throughput`：稳态区间内完成次数 / 区间长度。
- **利用率** `Utilization`：稳态区间“占用服务台数”时间平均 / 服务台数；
  发送方阻塞期间服务台计为占用。
- **排队时长**：到达工作站到开始服务的等待时间（抢占恢复不重复计时）。
- **逗留时长**：到达工作站到本站服务完成的时间。
- **时间平均等待队长** `MeanQueueLength`：仅等待队列。
- **时间平均站内人数** `MeanNumberInSystem`：等待 + 服务中 + 阻塞中
  （M/M/1 解析解 L = ρ/(1−ρ) 对应此口径）。
- **分位数**：nearest-rank（取秩上取整）定义，无插值、确定可复现；
  默认输出 p50/p90/p95/p99。
- **批均值置信区间**：把稳态区间等分为 `BatchCount` 个时间批。时长样本按
  观测时刻归入对应批，时间持久型量在每批区间独立积分；对批均值用
  Student-t（自由度 b−1）给出 `Confidence`（如 0.95）水平的半宽。
- 并行复制的跨复制标准差是“复制点估计”的样本标准差（自由度 n−1）。

## 代码结构

| 路径 | 职责 |
| --- | --- |
| `rng/` | 确定性 PCG 随机流、独立子流、状态保存/恢复 |
| `dist/` | 指数/均匀/常数/Erlang 分布与带类型标签的 JSON 序列化 |
| `stats/` | 样本累加、分位数、时间加权平均、批均值、t 分布置信区间 |
| `qsim/` | 顾客、策略、工作站、网络、事件表、仿真主循环、阻断/抢占、检查点 |
| `experiment/` | 并行独立复制与跨复制统计合并 |
| `cmd/qsimdemo/` | 本地可运行示例 |

## 最小用法

```go
cfg := &qsim.Config{
    Blocking: qsim.Reject, Seed: 42,
    Warmup: 1000, EndTime: 20000, BatchCount: 20, Confidence: 0.95,
    Network: &qsim.NetworkConfig{
        Model:          qsim.Open,
        ExternalArrive: []float64{4},
        Routing:        [][]float64{{0}},
        Stations: []qsim.StationConfig{{
            Name: "s", Servers: 1, Capacity: -1, Policy: qsim.FCFS,
            Service: dist.Exponential{Rate: 5}, // M/M/1, ρ = 0.8
        }},
    },
}
sim := qsim.New(cfg)
sim.Run(0)
report := sim.Report()
```

检查点续跑：

```go
sim := qsim.New(cfg)
sim.StepUntil(cut)
snap, _ := sim.Save()
data, _ := snap.Marshal()
loaded, _ := qsim.UnmarshalSnapshot(data)
resumed, _ := qsim.RestoreSnapshot(loaded)
resumed.Run(0) // 报告与一次连续运行完全一致
```

并行复制：

```go
summary, _ := experiment.RunAndAggregate(cfg, 16)
```
